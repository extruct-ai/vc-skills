# Positioning Axes Reference

Standard axes for mapping competitive landscapes. Select 3-5 that are most meaningful for the specific market.

## Axis 1: Breadth vs Depth

| Pole | Description |
|------|-------------|
| **Breadth** (Suite) | All-in-one platform covering many functions. Fewer best-in-class features, more workflow integration. |
| **Depth** (Point Solution) | Focused tool that does one thing exceptionally well. Deep functionality in a narrow area. |

**When this axis matters:** Markets where buyers choose between "one tool for everything" vs "best tool for each job." Common in enterprise software.

**Scoring guide:**
- 1 = Pure point solution, single function
- 2 = Focused tool with minor adjacent features
- 3 = Multi-feature product, clear core + add-ons
- 4 = Broad platform covering several functions
- 5 = Full suite / all-in-one platform

## Axis 2: SMB vs Enterprise

| Pole | Description |
|------|-------------|
| **SMB** | Targets small teams (1-200 employees). Low price, self-serve, fast onboarding, simple. |
| **Enterprise** | Targets large orgs (1000+). High price, sales-led, long implementation, complex. |

**When this axis matters:** Almost always relevant. Defines pricing, sales model, product complexity, and competitive dynamics.

**Scoring guide:**
- 1 = Pure SMB / freelancer (free tier, <$50/mo)
- 2 = SMB-focused with mid-market aspirations
- 3 = Mid-market core ($500-5K/mo, mix of self-serve and sales)
- 4 = Enterprise-focused with mid-market entry
- 5 = Pure enterprise ($50K+ ACV, named accounts, long sales cycles)

## Axis 3: Self-Serve vs Sales-Led

| Pole | Description |
|------|-------------|
| **Self-Serve** | Product-led growth. Users sign up, try, buy without talking to sales. Freemium or free trial. |
| **Sales-Led** | Outbound sales, demos, procurement. Users cannot buy without engaging sales. |

**When this axis matters:** Markets where go-to-market approach is a key differentiator. Overlaps with SMB/Enterprise but not always — some enterprise products are PLG.

**Scoring guide:**
- 1 = Fully self-serve, no sales team
- 2 = PLG with optional sales assist
- 3 = Hybrid (self-serve entry, sales for expansion)
- 4 = Sales-assisted (demo required for most deals)
- 5 = Fully sales-led (RFP, procurement, no self-serve)

## Axis 4: Simple vs Powerful

| Pole | Description |
|------|-------------|
| **Simple** | Easy to learn, limited configuration. Opinionated defaults. Trades power for usability. |
| **Powerful** | Highly configurable, steep learning curve. Flexible but complex. Trades usability for capability. |

**When this axis matters:** Markets where product complexity is a real trade-off. Developer tools, analytics, workflow automation.

**Scoring guide:**
- 1 = Dead simple, no configuration, 5-minute setup
- 2 = Simple with light customization
- 3 = Moderate complexity, training helpful
- 4 = Complex, requires dedicated admin or specialist
- 5 = Highly technical, steep learning curve, maximum flexibility

## Axis 5: Horizontal vs Vertical

| Pole | Description |
|------|-------------|
| **Horizontal** | General-purpose, works across industries. Same product for healthcare, finance, retail. |
| **Vertical** | Industry-specific. Built for one industry with specialized features, data models, compliance. |

**When this axis matters:** Markets where industry specialization creates defensibility. Healthcare, finance, construction, logistics.

**Scoring guide:**
- 1 = Fully horizontal, industry-agnostic
- 2 = Horizontal with light industry templates
- 3 = Multi-vertical (serves 2-3 industries deeply)
- 4 = Vertical-focused with one primary industry
- 5 = Pure vertical play, single industry only

## Selecting Axes

For a given market, select the 3-5 most differentiating axes:

1. **Always include:** SMB vs Enterprise (almost always relevant)
2. **Include if:** Breadth/Depth — if the market has both suites and point solutions
3. **Include if:** Self-Serve/Sales-Led — if GTM approach varies significantly
4. **Include if:** Simple/Powerful — if product complexity is a real differentiator
5. **Include if:** Horizontal/Vertical — if industry specialization matters

You can also define **custom axes** specific to the market:
- AI-native vs Traditional
- Open source vs Proprietary
- Cloud-only vs Hybrid/On-prem
- Data-first vs Workflow-first
